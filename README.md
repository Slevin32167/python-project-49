# Brain Games

Набор из 5 мини-игр для тренировки мозга, написанных на Python.

## Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/Slevin32167/python-project-49.git

# Перейдите в папку проекта
cd python-project-49

# Установите пакет
make package-install

Игры
brain-even
Проверка на четность. Ответьте "yes" если число четное, иначе "no".

bash
brain-even
brain-calc
Арифметические операции. Вычислите результат выражения.

bash
brain-calc
brain-gcd
Наибольший общий делитель. Найдите НОД двух чисел.

bash
brain-gcd
brain-progression
Арифметическая прогрессия. Найдите пропущенное число.

bash
brain-progression
brain-prime
Простое ли число? Ответьте "yes" если число простое, иначе "no".

bash
brain-prime
